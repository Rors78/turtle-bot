# Turtle Sue Icon

This directory contains the official icon for **Turtle Sue** - the badass turtle trading bot!

## Icon Design

The icon features:
- **A sleek turtle** with hexagonal shell pattern (representing structured trading)
- **Green gradient** (bullish vibes! 📈)
- **Trading chart accent** on the shell showing upward movement
- **Dollar sign** accent (because we're here to make money!)
- **Professional dark background** matching the dashboard aesthetic

## Installation

The icon is automatically installed to:
- `~/.local/share/icons/hicolor/scalable/apps/turtle-sue.svg`

## Desktop Entry

The desktop launcher is available at:
- Desktop: `~/Desktop/TurtleBot.desktop`
- Applications menu: `~/.local/share/applications/turtle-sue.desktop`

Just double-click the icon on your desktop or search for "Turtle Sue" in your applications menu!

## Icon Specifications

- **Format**: SVG (Scalable Vector Graphics)
- **Size**: 512x512 viewBox (scales to any size)
- **Color scheme**: Green (#10b981, #34d399), Gold (#fbbf24), Dark (#1a1f2e)
- **Style**: Modern, professional, trading-themed
